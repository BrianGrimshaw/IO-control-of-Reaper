# IO-control-of-Reaper
Switch Reaper (DAW) effects on an off from physical pushbuttons. Indicate Status on LEDs

I use Reaper as my DSP for the stereo and for the TV sound
I wanted to turn a compressor on for late night viewing - we live in a flat, but couldn't find anything suitable until I found this USB GPIO:
https://numato.com/docs/8-channel-usb-gpio-module-with-analog-inputs/

I got a small box, some LEDs and some small illuminated pushbuttons and made this box - middle one on the last photo:
